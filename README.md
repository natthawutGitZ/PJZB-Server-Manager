# PJZB Server Manager

โปรแกรม Windows สำหรับจัดการ Project Zomboid Dedicated Server Build 42 ผ่านหน้าจอเดียว รองรับ Start/Stop, Live Log, Configuration, Sandbox, Mods, Workshop, Players/RCON, Backup และ Updates

## ดาวน์โหลด

ดาวน์โหลด `.exe` รุ่นล่าสุดจาก [GitHub Releases](https://github.com/natthawutGitZ/PJZB-Server-Manager/releases/latest) โปรแกรมเป็น Self-contained สำหรับ Windows 10/11 64-bit และไม่ต้องติดตั้ง .NET เพิ่ม

## เอกสาร

- [คู่มือการใช้งานภาษาไทย](docs/MANUAL_TH.md)
- [แจ้งปัญหา](https://github.com/natthawutGitZ/PJZB-Server-Manager/issues)

## คุณสมบัติหลัก

- First-Time Setup ติดตั้ง SteamCMD และ Dedicated Server อัตโนมัติ
- นำ Server root เดิมมาใช้โดยคงข้อมูลโลกและผู้เล่น
- รองรับ Dedicated Server, Forward Port และ playit.gg
- Dark UI พร้อม Live Log แยกสี
- แก้ Server Configuration และ Sandbox แยก Base Game/Mods
- จัดการ Mods, Steam Workshop และผู้เล่นผ่าน RCON
- สร้าง, Restore, ลบ Backup และตรวจ Updates

> เครื่องมือนี้เป็นโครงการชุมชน ไม่ใช่ผลิตภัณฑ์อย่างเป็นทางการของ The Indie Stone, Valve หรือ playit.gg
